## Astro and Cloudflare Workers

This repository uses Astro SSR with `@astrojs/cloudflare`. Read the relevant Astro and Cloudflare guides under `node_modules/` before changing the application or deployment configuration. Keep the Node.js baseline at the version declared in `.nvmrc` and `package.json`.

The production entry point is generated by the Cloudflare adapter. Do not edit files under `dist/` or `.astro/`; change the Astro source and run `pnpm build` to regenerate them.
